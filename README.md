<h1 align="center">ICS Newspaper Publications Archive</h1>

<br>

This repository contains all publications (to date) of the [ICS](https://can.k12.tr/) school newspaper. Article texts and images are written and selected by members of the ICS Journalism Club. I am only responsible for the design, layout, and typesetting of the newspaper.

My Adobe InDesign template for the newspaper (and associated config) can be found [here](https://github.com/samyarsadat/ICS-Newspaper-Template).
